# 🧠 Mentalist

## 📊 Collaborative Data Science and Machine Learning Project

**Mentalist** is a collaborative **Data Science and Machine Learning** project.  
The main objective is to provide a shared workspace where team members can develop, organize, document, and share their data analysis and machine learning work.

## 🎯 Objectives

The main objectives of the project are:

- 🔍 Data understanding and exploration
- 🧹 Data cleaning and preprocessing
- 📊 Exploratory Data Analysis (EDA)
- 📈 Data visualization
- ⚙️ Feature engineering
- 🤖 Machine Learning model development
- 📏 Model evaluation and comparison
- 📓 Sharing Jupyter and Google Colab notebooks
- 👥 Team collaboration and version control

## 📁 Project Structure

```text
Mentalist/
│
├── 📓 notebooks/
│   └── Jupyter and Google Colab notebooks
│
├── 📂 data/
│   └── Project datasets
│
├── 🐍 src/
│   └── Python source code
│
├── 📊 reports/
│   └── Reports, results, and generated figures
│
└── 📄 README.md
    └── Project documentation
```

### 📓 `notebooks/`

Contains the Jupyter and Google Colab notebooks used throughout the project, including data understanding, preprocessing, EDA, modeling, and evaluation.

### 📂 `data/`

Contains the datasets used for the project.

### 🐍 `src/`

Contains reusable Python scripts and functions used for data processing and machine learning.

### 📊 `reports/`

Contains project reports, generated results, visualizations, and figures.

## 👥 Team

This repository is used by the project team to collaborate, share notebooks, track changes, and maintain the different stages of the Data Science workflow.

Each team member can contribute by creating or updating notebooks, adding Python code, documenting experiments, and committing their work to the repository.
